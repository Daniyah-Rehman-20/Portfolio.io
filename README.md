# Daniyah Rehman — Portfolio

Recruiter-focused personal portfolio for Daniyah Rehman.

## Stack
- Static HTML/CSS/JavaScript
- No build step
- Responsive and accessible
- Ready for Vercel, Netlify, or GitHub Pages

## Deploy to Vercel
1. Create a GitHub repository (for example `portfolio-2026`).
2. Add `index.html`, `vercel.json`, and this README.
3. Import the repository into Vercel.
4. Framework preset: **Other**. No build command is required.

## Customize links
Project cards intentionally show live/repository links only where a verified URL was available. Add missing GitHub/demo URLs directly to the relevant `.project-links` block in `index.html`.
